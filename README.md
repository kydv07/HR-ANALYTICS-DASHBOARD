# HR Analytics Dashboard 

## Project Overview

This project presents an interactive **HR Analytics Dashboard** built using **Tableau** to analyze employee attrition, workforce demographics, and job satisfaction trends.

The dashboard helps HR teams understand workforce patterns and identify major factors influencing employee attrition.




## Objective

The main objectives of this project are:

* Analyze employee attrition across departments
* Compare attrition by gender and age groups
* Study job satisfaction by job role
* Identify education field trends related to attrition
* Support HR decision-making using visual analytics

---


##  Tools Used

* Tableau
* Microsoft Excel / CSV Dataset

## Dashboard KPIs

* Employee Count: **1,470**
* Attrition Count: **237**
* Attrition Rate: **16.12%**
* Active Employees: **1,233**
* Average Age: **37**




## Dashboard Features

### Department-wise Attrition

Shows attrition distribution across:

* HR
* R&D
* Sales

### Employee Distribution by Age Group

Histogram showing employee count by age.

### Attrition by Gender

Comparison of male and female attrition.

### Job Satisfaction Rating

Heatmap analysis of satisfaction levels across job roles.

### Education Field-wise Attrition

Bar chart showing attrition by education background.

### Attrition by Age Group and Gender

Donut charts comparing attrition across:

* Under 25
* 25–34
* 35–44
* 45–54
* Over 55
